# Apex Innovators — SIH 2026

## AI-Powered Email Threat Detection, Geolocation and Forensic Intelligence Platform

An AI-powered cybersecurity platform designed to analyze suspicious emails, identify potential phishing and spoofing attempts, and generate actionable forensic intelligence for faster incident response.

---

## Problem Statement

Email-based cyber threats such as phishing, spoofing, malicious links, and social engineering continue to pose significant security risks.

Investigating suspicious emails can require multiple tools and manual analysis, which may delay detection and response.

---

## Proposed Solution

Our proposed platform aims to provide a unified workflow for analyzing suspicious emails.

A user can submit an email for analysis, after which the platform is designed to:

- Detect potential phishing and spoofing indicators
- Analyze email headers and available metadata
- Identify suspicious links and other threat indicators
- Correlate relevant technical information
- Generate a structured forensic report
- Present findings in an easy-to-understand format for investigation

Geolocation and attribution capabilities will be based on legally and technically available evidence. The system will not assume that an IP address or network identifier automatically reveals an attacker's physical location or identity.

---

## Key Features

- AI-assisted email threat analysis
- Phishing and spoofing detection
- Email header and metadata analysis
- Suspicious URL and indicator analysis
- Forensic evidence organization
- Automated report generation
- Investigator-friendly results dashboard
- Designed for faster cybersecurity incident response
